# Shubham & Pratiksha — Wedding Invitation

A lightweight, mobile-first wedding invitation website built with plain HTML, CSS, and JavaScript.

## Preview locally

Open `index.html` in a browser. The countdown, calendar download, responsive photo gallery, and sharing button work without a build step.

## Publish with GitHub Pages

1. Push the project files to the `main` branch of `shubhamshelar774/wedding-invitation`.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. Once Pages finishes deploying, the invitation will be available at `https://shubhamshelar774.github.io/wedding-invitation/`.

The venue link, countdown, and calendar event are set to 20 December 2026 at 2:35 PM India Standard Time.
